The question

Chapter 2 computed F from known camera poses. In practice we only have images: a feature matcher (SIFT, ORB, SuperPoint + LightGlue…) gives pixel correspondences x₁ ↔ x₂, some of them noisy and some plain wrong. From those we want F, and from F (with K) the relative pose — the first step of every SfM / SLAM pipeline.

1. The 8-point algorithm

Each match gives one linear equation in the 9 entries of F:

one matchx₂ᵀ F x₁ = 0 ⇔ [x₂x₁, x₂y₁, x₂, y₂x₁, y₂y₁, y₂, x₁, y₁, 1] · f = 0
n matchesA f = 0, A ∈ ℝⁿˣ⁹
solvef = singular vector of A with the smallest singular value
rank 2F = U diag(σ₁, σ₂, 0) Vᵀ

F has 9 entries up to scale, so 8 matches determine it (7 with the rank constraint: the 7-point algorithm). The least-squares solution does not have rank 2 in general; zeroing the smallest singular value gives the closest rank-2 matrix so that all epipolar lines meet at one epipole.

2. Why normalize (Hartley, 1997)

With raw pixels the columns of A have wildly different scales: x₂x₁ ~ 10⁵ next to 1. AᵀA is badly conditioned and the least-squares solution weights the equations badly, so noise is amplified. The fix is cheap: translate each image's points to have centroid 0 and scale them so the mean distance is √2,

x̂ = T x, F̂ from x̂ matches, F = T₂ᵀ F̂ T₁

Compare the two 8-point rows in the Lab with 0% outliers: same data, same algorithm, several times less error.

3. RANSAC (Fischler & Bolles, 1981)

Least squares has no defence against outliers: one wrong match can ruin F. RANSAC repeats:

  1. pick a minimal random sample (8 matches),
  2. fit F to it,
  3. count the matches that agree, i.e. whose epipolar distance is below a threshold τ (the inliers),

keeps the hypothesis with the most inliers and finally refits F on all of its inliers. To get at least one outlier-free sample with probability p, with outlier ratio ε and sample size s, it needs

N = log(1 − p) / log(1 − (1 − ε)ˢ)

For s = 8, p = 0.99: ε = 25% → 44 iterations, ε = 50% → 1177. That is why minimal solvers matter: the 5-point algorithm for E needs far fewer samples (ε = 50% → 146).

4. Things to try

  • Set outliers to 0 and compare raw and normalized 8-point while increasing σ.
  • Add 10% outliers: both plain 8-point estimates break, epipolar lines tilt away from the true ones.
  • Run RANSAC step by step: the yellow rings are the current sample. Most samples with an outlier get few inliers.
  • Make τ very small (true inliers get rejected) or very large (outliers get accepted).
